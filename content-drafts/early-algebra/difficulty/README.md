# Early Algebra difficulty-specific encounter drafts

This folder contains 32 local sidecars: eight songs × four chart difficulties. Each Hit is placed on an actual note tick from the corresponding selected chart section. Linked Spin and Drag events keep their original offset from the source Hit; equation IDs, encounter IDs, target tokens, and the six authored equations per song are retained.

The timing pass keeps Hits at least 1.5 seconds apart. Across the candidates, the equations remain one-step integer forms (`x + n = m` or `x - n = m`) with positive solutions from 2 to 9. Per-file note counts, exact matches, maximum timing shifts, and chart source revisions are recorded in `manifest.json`.

The manifest records final exact chart-note matches separately from the number of baseline Hits that already matched before retiming. These files are reviewable local candidates. Publishing them still requires the Platform's authenticated save and publish flow; this generation did not modify hosted revisions.
